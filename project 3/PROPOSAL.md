## My Project Proposal

**What I'm building:** 
I am building a web that uses Flask to find the nearest MBTA station and allows the user to input name of a place or the address. It also displays if that station is wheelchair accessible or not with a map showing the distance between the two points.

**Why I chose this:** 
I chose this because I have recently found myself using the MBTA much more often this semester and I never know the closest exit to get off when I am somewhere away from Wellesley. I also think this would help me find nearby stations when I am in a location I am not familiar with.

**Core features:** 
- Use Mapbox Geocoding API and MBTA V3API to convert a place name into coordinates and find the nearest transit stop near the coordinates
- Create a webpage that displays the nearest stop and a map
- Allows users to input the name of the location or address
- Calculates the distance between the two points
